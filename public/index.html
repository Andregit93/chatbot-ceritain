Apa itu ceritAIn?

ceritAIn adalah chatbot konsultasi kesehatan mental berbasis Generative AI. Sistem ini dirancang khusus untuk memahami konteks percakapan bahasa Indonesia yang empatik, santai, dan bebas stigma. ceritAIn bertindak sebagai pendukung awal non-klinis untuk memvalidasi perasaanmu dan memberikan psikoedukasi ringan, menjaga keamanan pengguna sebagai prioritas utama.

Development Tools

Gemini 2.5 Flash

Menggunakan model Generative AI Gemini melalui arsitektur LangChain untuk pemrosesan bahasa alami.

Node.js & Express

Backend untuk menangani request secara asyncrhonous dan mengelola endpoint API.

PostgreSQL

Database relasional yang andal dengan Supabase untuk mengelola memori sesi percakapan secara aman.

Bootstrap

Framework antarmuka yang memastikan tampilan ceritAIn responsif dan mulus diakses lewat laptop maupun ponsel.
