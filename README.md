# ceritAIn - Chatbot Konsultasi Kesehatan Mental berbasis Generative AI

**ceritAIn** adalah aplikasi chatbot cerdas yang dirancang sebagai **asisten virtual kesehatan mental**. Aplikasi ini memberikan ruang aman bagi pengguna untuk bercerita, mengekspresikan emosi, dan mendapatkan respons yang **empatik, personal, dan kontekstual** menggunakan teknologi Generative AI.

Proyek ini dibangun menggunakan **Node.js, Express.js, Supabase**, serta model **Google Gemini** melalui framework **LangChain**.

---

## 🛠️ Teknologi yang Digunakan

### Frontend
- HTML5  
- CSS3  
- JavaScript (Vanilla)  
- Bootstrap 5  
- SweetAlert2  

### Backend
- Node.js  
- Express.js  

### Database
- PostgreSQL (Supabase)  
- JSONB untuk penyimpanan memori percakapan  

### AI Engine
- Google Gemini API  
- LangChain (`ChatGoogleGenerativeAI`)  

---

## 🚀 Cara Menjalankan Sistem

Ikuti langkah-langkah berikut untuk menjalankan aplikasi secara lokal:

### 1. Persiapan Lingkungan
Pastikan kamu sudah menginstall **Node.js** di perangkat kamu.

Clone repository:
```bash
git clone https://github.com/username/ceritAIn.git
cd ceritAIn
```

### 2. Instalasi Dependensi

Jalankan perintah berikut di terminal:
```bash
npm install
```

### 3. Menjalankan Server

Jalankan server dengan perintah:
```bash
node server.js
```

Buka browser dan akses:
```code
http://localhost:3000
```
